# legacy

Первая версия скилла и локального UI, из которой вырос mr-review. Оставлена для сверки процедур и
как источник примеров; пакет её не публикует и код не использует.

- `v1/SKILL.md`, `Review.md`, `Feedback.md`, `Criteria.md`, `Rules.md`, `Sources.md` — исходные
  процедуры для конкретного монорепозитория и файлового обмена через `.mr-review/`.
- `v1/code/server.mjs`, `v1/code/index.html` — прежний локальный сервер и UI на ванильном JS.
  Запускались вручную на хосте и общались с агентом через JSON-файлы.

Актуальные версии: `skills/mr-review/`, `src/`, `ui/`.
