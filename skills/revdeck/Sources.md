# Источники данных

Использовать первый доступный способ. Все команды только читающие.

## Контекст ревью

1. MCP: `revdeck_context` — выжимка, файлы, правила, треды, замечания, комментарии человека.
2. CLI: `revdeck context <номер или URL>` — то же в markdown; `--json` — структурировано.
3. Если ревью ещё не открыто: `revdeck_open` / `revdeck open <N|URL>`. Без аргумента revdeck
   ищет открытое ревью текущей ветки.

## Треды и diff

- Треды: `revdeck_threads` / `revdeck threads <N> [--json]`.
- Список файлов: `revdeck_diff` / `revdeck diff <N>`.
- Hunks файла: `revdeck_diff` с `file` / `revdeck diff <N> --file <путь>`.
- Номера строк — по новому файлу; в hunk есть `newLine` и `oldLine`.

## Описание MR

Приходит в `revdeck_context` (`info.description`), в `revdeck open` и в `revdeck context`.
Если описание пустое, сказать об этом в выжимке и не сравнивать его с diff.

## Правила проекта

Эффективные правила вычисляет revdeck: `rules.map` из `.revdeck.yml` плюс автообнаружение
(`AGENTS.md`, `CLAUDE.md`, `CONTRIBUTING.md`, `docs/*`). В контекст попадают только документы и
секции для изменённых путей, поэтому не нужно читать весь `docs/` и нельзя подменять правила
общими best practices.

Если в контексте есть предупреждение «документ не найден» или путь не сопоставлен — сказать об
этом и оценивать по запасному правилу (только корневые `AGENTS.md`/`CONTRIBUTING.md`/README),
а пробел оформить кандидатом в правила (`Rules.md`).

## Локальная ветка без платформы

1. `git log --oneline <база>..HEAD` и `git diff <база>...HEAD` — база по умолчанию из
   `.revdeck.yml` (`provider.base`) или `develop`/`main`.
2. Вставить diff в чат или использовать `revdeck context` с номером, если ревью есть на платформе.

## Ограничения среды

- В контейнере без доступа к сокету демона используйте `REVDECK_URL` + `REVDECK_TOKEN`
  (порт локального демона, проброшенный на хост) или попросите человека выполнить команду на хосте.
- Не устанавливать `glab`/`gh` в песочнице и не просить токен: доступ к платформе есть только у
  демона на хосте.
